# Генетический алгоритм для метрической задачи коммивояжёра

Исследовательский проект: реализация и экспериментальное сравнение генетического алгоритма с различными операторами для поиска кратчайшего гамильтонова цикла в метрических графах.  

## Структура репозитория

- `Gen.py` - основной код: генераторы тестовых графов, реализация генетического алгоритма, MST 2-приближение, функции сбора статистики и визуализации.
- `TSP Genetic Algorithm.pdf` - текст работы с теоретическим анализом сложности, описанием алгоритмов и результатами экспериментов.

## Возможности

- Генерация тестовых наборов:
  - малые графы (N ≤ 10) для сравнения с полным перебором;
  - равномерное случайное распределение;
  - кластерное распределение (имитация групп городов);
  - кольцевое распределение.
- Точный алгоритм полного перебора для малых N.
- Детерминированный 2-приближённый алгоритм на основе минимального остовного дерева (MST).
- Генетический алгоритм с настраиваемыми компонентами:
  - Инициализация: случайная или смешанная (10% жадных особей).
  - Скрещивание: Ordered Crossover (OX) или Partially Mapped Crossover (PMX).
  - Мутация: Swap, Inversion, Scramble.
  - Отбор: турнирный (k=3) с элитизмом (2 лучшие особи сохраняются).
- Автоматический запуск серии экспериментов (40 запусков для каждой конфигурации), расчёт статистик: минимум, максимум, среднее, медиана, стандартное отклонение, время выполнения, улучшение относительно MST.
- Визуализация сходимости алгоритмов (графики лучшего найденного расстояния по поколениям).

## Запуск

```bash
python Gen.py
```

## При выполнении:

- автоматически прогоняются все тестовые наборы (малый, равномерный, кластерный, кольцевой);
- в консоль выводится статистика по каждому варианту (мин, макс, среднее, медиана, std, время, процент улучшения относительно MST);
- после обработки каждого набора открывается окно matplotlib с графиком сходимости всех трёх конфигураций алгоритма.

## Зависимости

- Python 3.8+
- numpy
- scipy
- matplotlib
- networkx

Установка:

```bash
pip install numpy scipy matplotlib networkx
```

## Основные результаты
На кольцевых графах (N=50) комбинация смешанной инициализации, Ordered Crossover и Inversion-мутации показала улучшение маршрута на 36,14% по сравнению с MST 2-приближением при практически нулевой дисперсии.
